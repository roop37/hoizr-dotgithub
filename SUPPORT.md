# Getting help

Hoizr is maintained by a small team. These are the best places to get an answer.

## Read the docs first

- [hoizr-walkthrough](https://github.com/roop37/hoizr-walkthrough) is a guided tour of the whole system: architecture, service boundaries and how a request flows between the ten repositories.
- The [local development guide](https://github.com/roop37/hoizr-walkthrough/blob/main/docs/09-local-development.md) covers prerequisites, environment variables, start order and codegen.
- Each repository's README covers setup and scripts for that repository.
- [CONTRIBUTING.md](https://github.com/roop37/hoizr-dotgithub/blob/main/CONTRIBUTING.md) explains which repository owns what, and how to install the `@hoizr-technology/shared` package from GitHub Packages.

## Where to ask

| You have... | Go to |
|---|---|
| A question about how something works or how to set it up | GitHub Discussions on the relevant repository, if Discussions is enabled there. Otherwise open an issue with the **Documentation** form and describe what was unclear. |
| A bug | An issue in the affected repository, using the **Bug report** form. |
| A feature idea | An issue using the **Feature request** form. For large ideas, describe the problem before the solution. |
| A security vulnerability | **Not a public issue.** Follow the [security policy](https://github.com/roop37/hoizr-dotgithub/blob/main/SECURITY.md). |
| A code of conduct concern | Email [contact@hoizr.com](mailto:contact@hoizr.com), as described in the [Code of Conduct](https://github.com/roop37/hoizr-dotgithub/blob/main/CODE_OF_CONDUCT.md). |

Search existing issues and discussions before opening a new one; your question may already have an answer.

## What to include

A good question gets a faster answer. Please include:

- Which repository (or repositories) you are working with, and the commit you are on.
- What you were trying to do, what you expected, and what happened instead.
- The exact command you ran and the full error output, as text rather than a screenshot.
- Your environment: operating system, Node.js version, package manager, and MongoDB and Redis versions (or Flutter version for the scanner app).
- Which other Hoizr services were running at the time.

Remove secrets, tokens and personal data from logs and screenshots before you post them.

## Response times

Maintainers answer issues and discussions on a best-effort basis. There is no paid support for the open-source code.
